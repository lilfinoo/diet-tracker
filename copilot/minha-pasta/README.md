# Catálogo nutricional local

`alimentos.json` é usado pelo navegador para busca e preenchimento rápido de alimentos no diário.

O catálogo é uma compilação original criada pelo autor do Fit-Tracker.AI, sem cópia de base proprietária de terceiros. Salvo indicação diferente no repositório, o autor reserva todos os direitos sobre essa compilação. Os valores são referências aproximadas para busca e preenchimento, não substituem rótulos ou avaliação profissional.

O catálogo não é enviado integralmente ao Gemini durante a geração de planos alimentares. Nessa funcionalidade, as metas energéticas são calculadas pelo backend e os macros das refeições são estimativas aproximadas da IA, validadas contra tolerâncias programáticas.
